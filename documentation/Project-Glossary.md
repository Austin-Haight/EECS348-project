# Project Glossary
**Project Title:** Arithmetic Expression Evaluator in C++

**Version:** 1.1

**Date:** March 2026

## UPEDU
**The Unified Process for EDUcation (UPEDU):** A set of project artifact templates we will be using for this project’s documentation.

## CLI
**Command Line Interface** that enables a user to interact with the program through a command line or shell.

## SRS
**Software Requirements Specification** to document the system requirements.

## PEMDAS
Order of operations: Parentheses, Exponents, Multiplication/Divide, Addition/Subtraction.

## Token
A unit of an expression, including a number, operator, or parenthesis.

## Unary/Binary Operator
An operator that acts on a single/two operand(s).
